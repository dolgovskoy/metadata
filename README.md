Metadata Cleaner

Metadata Cleaner - графическое приложение на Python для просмотра и удаления метаданных изображений.

Проект создан dolgovskoy и впоследствии дорабатывается совместно с Shadow1874.

Возможности

Открытие изображений в форматах JPG, JPEG, PNG и TIFF.

Просмотр EXIF-метаданных.

Отображение информации об изображении в виде таблицы.

Удаление метаданных с сохранением отдельной копии файла.

Возможность самостоятельно выбрать место и имя сохранения.

Ведение журнала работы приложения.

Локальная обработка изображений без отправки файлов на внешние серверы.

Используемые технологии

Python - основной язык программирования.

Tkinter - создание графического интерфейса.

Pillow - обработка изображений и работа с метаданными.

Logging - запись событий и ошибок в журнал.

Требования

Python 3.8 или новее.

Установленная библиотека Pillow.

Установка

Клонируйте репозиторий:

git clone https://github.com/Shadow1874/Metadata-Cleaner.git

Перейдите в папку проекта:

cd Metadata-Cleaner

Установите необходимые зависимости:

pip install Pillow

Запуск

Для запуска приложения выполните команду:

python main.py

Использование

Запустите приложение.

Нажмите кнопку «Открыть изображение».

Выберите нужный файл на компьютере.

Просмотрите доступные свойства и EXIF-метаданные в таблице.

Нажмите кнопку «Удалить метаданные».

Выберите место сохранения и имя нового файла.

Обработанное изображение сохраняется отдельно. Исходный файл не изменяется.

Журнал работы

Приложение автоматически записывает основные события и возникающие ошибки в файл app_log.txt, расположенный в той же папке, что и скрипт.

Особенности работы

Программа создаёт новое изображение на основе пиксельных данных исходного файла, не перенося исходные метаданные.

Повторное сохранение изображения может изменить некоторые его характеристики, например параметры сжатия, цветовой профиль и особенности исходного формата.
